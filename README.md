# คุณหนูใหญ่ซ่งอวิ๋น

นิยายภาพภาษาไทยจากต้นฉบับของซีอิ๋ง เปิด [หน้าแรก](index.html) เพื่อเลือกตอน หรือเปิด [ตอนที่ 1](read/01.html) เพื่อเริ่มอ่าน

## ต้นฉบับและภาพประกอบ

- `content/` เก็บข้อความตอนที่ 1–30 ข้อมูลหน้าปก และรูปปกต้นฉบับ
- `references/` เก็บภาพต้นแบบที่ใช้ระหว่างผลิตในเครื่อง
- `assets/characters/` เก็บชีตตัวละครที่ใช้เทียบใบหน้าก่อนเจนภาพฉาก
- [ทะเบียนตัวละคร](production/characters.json) ระบุบทบาท ภาพต้นแบบ ชีตตัวละคร และแนวภาพที่ใช้ทุกตอน
- แผนตอน [1–10](production/chapters-01-10.json), [11–20](production/chapters-11-20.json) และ [21–30](production/chapters-21-30.json) เก็บรายละเอียดฉากและเลขย่อหน้าที่แทรกภาพ ภาพฉากอยู่ใน `assets/illustrations/` ตามเลขตอนและลำดับฉาก

เมื่อต้องทำภาพเพิ่ม ให้อ่านฉากกับชีตของตัวละครในฉากก่อน ใช้ชีตคนเดิมทุกครั้ง แล้วปรับเสื้อผ้า มุมกล้อง ท่าทาง และสีหน้าให้ตรงเหตุการณ์ จัดเก็บภาพตามเลขในแผน แล้วสร้างหน้าอ่านใหม่จากไฟล์ต้นฉบับ

```powershell
py -3 -X utf8 tools/build_reader.py --require-art
```

หน้าอ่านทั้ง 30 ตอนเปิดจาก `index.html` ได้โดยตรง และใช้พาธสัมพัทธ์เพื่อให้เปิดได้จาก GitHub Pages
