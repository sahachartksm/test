# Love · บ้านกระจก

นิยายโต้ตอบภาษาไทยจากมุมของกานต์ จากวันมาถึงบ้านกระจกจนถึงเช้าปีใหม่ เล่นบนมือถือและเดสก์ท็อปได้ที่ [GitHub Pages](https://sahachartksm.github.io/test/) หรือเปิด [index.html](index.html) ในเบราว์เซอร์เพื่อเล่นออฟไลน์

## วิธีเล่น

1. กด **เริ่มเรื่องใหม่** แล้วเลือกหนึ่งในสี่ช่องเซฟ
2. หลังฉากเปิดของแต่ละวัน เลือกว่าจะไปพบดาริน ใบชา หรือเฟื่อง การไปตามนัดและสิ่งที่พูดมีผลต่อสิ่งที่ทั้งสามตัดสินใจ
3. คืนฮาโลวีนกานต์รับปากช่วยได้คนเดียวต่อเซฟ ลงมือให้เสร็จ กลับมาตามนัดในตลาดปลายปี และเลือกคุยต่อในคืนคริสต์มาส ผลจบของอีกสองเส้นยังเปลี่ยนตามชีวิตของเธอเอง
4. เปิด **ผังเส้นทาง** ระหว่างอ่านหรือจากบทส่งท้าย ช่องสีทองบอกว่าคุณผ่านใครในวันไหนและกดเพื่อย้อนอ่านฉากได้ **บันทึก** เก็บเบาะแสและเหตุการณ์ที่เกิดนอกฉาก
5. กด **เซฟเกม** เพื่อเล่นต่อหรือคัดลอกเซฟไปลองอีกทาง เซฟเก็บในเบราว์เซอร์ของอุปกรณ์ที่เล่น เซฟฉบับก่อนที่จบแล้วมีปุ่ม **เล่นต่อคืนฮาโลวีน**

เกมใช้บทและภาพที่สร้างไว้ในโปรเจกต์ เหตุการณ์บางช่วงและบทส่งท้ายเปลี่ยนตามการเลือก คำตอบที่ได้รับ แผนที่รักษาไว้ และความสัมพันธ์ที่เกิดขึ้นนอกฉาก
