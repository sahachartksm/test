# Love · บ้านกระจก

นิยายโต้ตอบภาษาไทยจากมุมของกานต์ หลังตกงานเขากลับมาขอพักกับเฟื่องที่คาเฟ่บ้านกระจก เปิด [index.html](index.html) ในเบราว์เซอร์เพื่อเล่นออฟไลน์บนมือถือหรือเดสก์ท็อป มีสามเส้น ฉากจบ 12 แบบ และภาพตัวละครใหม่ 122 ภาพ ตั้งแต่บทนำถึงฉากจบ

## วิธีเล่น

1. กด **เริ่มเรื่องใหม่** แล้วเลือกหนึ่งในสี่ช่องเซฟ
2. เลือกที่พัก ถ้าเริ่มที่คาเฟ่ เลือกภาพกับดารินได้ตามชอบ แล้วเลือกว่าวันต่อไปจะนัดเจอใคร ปุ่มจะระบุเส้นที่จะเข้า ได้แก่ Alpha ของดาริน Beta ของใบชา และ Gamma ของเฟื่อง แต่ละเส้นเล่นต่อจนถึงฉากจบของตัวเอง
3. เปิด **ผังเส้นทาง** จากหน้าหลักได้ทันที ในเซฟที่กำลังเล่น กดฉากที่ผ่านแล้วเพื่อย้อนอ่าน หรือเปิดรายการฉากจาก **บันทึก**
4. เกมบันทึกอัตโนมัติเมื่อเปลี่ยนฉาก กด **เล่นต่อ** จากหน้าหลักเพื่อเลือกเซฟ หรือกด **เซฟเกม** ระหว่างอ่านเพื่อคัดลอกเซฟไปยังช่องว่าง
5. เปิด **ฉากจบ** จากหน้าหลักเพื่อดูฉากที่พบแล้ว หรืออ่าน **เรื่องที่กานต์ไม่เห็น** หลังจบเรื่อง
6. เมื่อจบแบบที่เธอเลือกคู่แข่ง จะมีปุ่ม **อ่านเรื่องหลังจบ** ของคู่นั้น บทหลังจบจำตอนที่อ่านล่าสุดในช่องเซฟ

เซฟจากฉบับเทศกาลมีป้าย **บทเดิม** ในเมนูเซฟและยังเล่นต่อจากตำแหน่งที่บันทึกไว้ได้ ฉบับที่เผยแพร่อยู่บน [GitHub Pages](https://sahachartksm.github.io/test/)

## ไฟล์ต้นทาง

- [สมองเรื่องและชีตตัวละคร](STORY_BRAIN.md) เป็นไฟล์สำหรับแก้บท ให้รัน `node tools/build-story.cjs` เพื่อสร้างไฟล์บทที่เกมโหลด
- [ภาพอ้างอิงตัวละคร](assets/references/) เก็บภาพต้นฉบับหมายเลข 1–6 ตามทะเบียนในสมองเรื่อง
- [ชุดพรอมป์และลิงก์ภาพฉาก](assets/IMAGE-PROMPTS.md) ภาพบทเปิดอยู่ใน `assets/scenes/alpha/` และภาพฉบับขยายอยู่ใน `assets/scenes/cinematic/` ภาพที่เลิกใช้เก็บในเครื่องที่ `assets/archive/unused-scenes/`
- รัน `node tools/test-story.cjs` เพื่อตรวจเส้นทาง ฉากจบ ภาพ และการอ่านเซฟบทเปิดเดิม

- [แผนโลกอิเซไก](ISEKAI_PLAN.md) มีชีตตัวละคร กติกาของจอก ลำดับตอน และแนวภาพ
