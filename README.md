# คู่มือทบทวนก่อนสัมภาษณ์ IT Support / Network

เว็บ checklist + เนื้อหาทบทวน แบบไฟล์เดียวจบ (single-file HTML) ไม่มี dependency ภายนอก เปิดได้ทั้งบนคอมและมือถือ

## ฟีเจอร์

- Checklist 3 ระดับ (หัวข้อใหญ่ / หัวข้อย่อย / หัวข้อ) ติ๊กระดับล่างครบแล้วระดับบนติ๊กเอง
- Progress bar รวม และแยกตามหัวข้อใหญ่
- กดที่ชื่อหัวข้อเพื่ออ่านเนื้อหาเต็ม 26 บท พร้อมตารางสรุปและกล่อง "มักถูกถามในสัมภาษณ์"
- ปุ่มก่อนหน้า/ถัดไป และปุ่มกลับหน้าหลัก
- ช่องเขียนสรุปด้วยคำของตัวเองในทุกหัวข้อ บันทึกอัตโนมัติ
- ส่งออกสรุปทั้งหมดเป็นไฟล์ `.md` และคัดลอกรายหัวข้อได้
- สลับธีม มืด / สว่าง / ตามระบบ
- บันทึกทุกอย่างไว้ใน localStorage ของเบราว์เซอร์ รีเฟรชแล้วไม่หาย

## เนื้อหาที่ครอบคลุม

1. ระบบ Network & Broadband — OSI Model, IP & Subnetting, DHCP/DNS/NAT/TCP-UDP, LAN vs WAN, ADSL & FTTH, PPPoE, VLAN
2. อุปกรณ์ฮาร์ดแวร์และเครือข่าย — โหมดของ Router/AP, 2.4 vs 5GHz, Wi-Fi 4/5/6, WPA2/WPA3, สาย UTP, ไฟสถานะอุปกรณ์
3. ระบบปฏิบัติการและแอปพลิเคชัน — ตั้งค่า Network Adapter, คำสั่ง CMD/Terminal, Outlook (POP3/IMAP/Exchange), Browser
4. ทักษะการแก้ปัญหา — ลำดับการไล่ปัญหา "อินเทอร์เน็ตใช้ไม่ได้" ตั้งแต่สอบถามขอบเขตจนถึงปิดงาน

## การใช้งาน

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย

หรือ deploy ผ่าน GitHub Pages: Settings → Pages → Source: Deploy from a branch → เลือก `main` / root

## หมายเหตุ

ข้อมูลที่ติ๊กและสรุปที่เขียนไว้ ถูกเก็บในเบราว์เซอร์ของเครื่องนั้น ๆ ไม่ได้ sync ข้ามอุปกรณ์ ถ้าต้องการเก็บถาวรให้กดปุ่มดาวน์โหลดสรุป `.md`
