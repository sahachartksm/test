# Love · บ้านกระจก

นิยายโต้ตอบภาษาไทยจากมุมของกานต์ มีบทนำ 8 ตอนหลัก และบทส่งท้าย เปิด [index.html](index.html) ในเบราว์เซอร์เพื่อเล่นออฟไลน์ รองรับหน้าอ่านแนวตั้งบนมือถือ

## วิธีเล่น

1. กด **เริ่มเรื่องใหม่** แล้วเลือกหนึ่งในสี่ช่องเซฟ
2. เมื่ออ่านฉากเปิดของแต่ละตอนแล้ว เลือกว่าจะไปพบดาริน ใบชา หรือเฟื่อง จากนั้นเลือกคำตอบท้ายฉาก การรับนัดและไปตามนัดมีผลต่อสิ่งที่คนอื่นตัดสินใจ
3. เปิด **บันทึก** เพื่อดูเบาะแสที่ถามมาและย้อนอ่านฉากที่เล่นผ่านแล้ว ปุ่ม **เปิดเรื่องนอกฉาก** แสดงสิ่งที่แต่ละคนทำระหว่างที่กานต์ไม่ได้อยู่ด้วย
4. กด **เซฟเกม** เพื่อมาเล่นต่อหรือคัดลอกเซฟไปลองบทสนทนาอีกทาง เซฟเก็บในเบราว์เซอร์ของอุปกรณ์ที่เล่น

เกมใช้บทและภาพที่สร้างไว้ในโปรเจกต์ เหตุการณ์บางช่วงและบทส่งท้ายเปลี่ยนตามการเลือก คำตอบที่ได้รับ แผนที่รักษาไว้ และความสัมพันธ์ที่เกิดขึ้นนอกฉาก
