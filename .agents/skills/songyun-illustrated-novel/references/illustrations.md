# การทำภาพประกอบ

พาธในเอกสารนี้นับจากรากโปรเจกต์ Songyun

## ตัวละคร

อ่านฉากจาก `content/chapter-NN.md` และเปิด `production/characters.json` ทะเบียนนี้จับชื่อในเรื่องเข้ากับไฟล์ต้นแบบ `reference` ชีตที่ใช้จริง `sheet` รายละเอียด `design` และพรอมป์ชีต `sheetPrompt`

ใช้ชีตที่ตรวจแล้วซ้ำทุกครั้งเมื่อเห็นหน้าตัวละคร หากยังไม่มีชีต ให้เลือกภาพใน `references/` เป็นแนวใบหน้าตัวละครหญิง ส่วนตัวละครชายที่ยังไม่มีภาพต้นแบบให้ออกแบบจากอายุ รูปลักษณ์ และบทบาทในเรื่อง ใช้ชื่อและรหัสเดิมจากทะเบียนเมื่อต่อยอดตัวละครที่มีอยู่

เจนชีตให้เห็นเต็มตัว มุมตรง มุมเฉียง ด้านข้าง และหลายสีหน้า ตรวจให้เห็นว่าเป็นคนเดียวกันก่อนบันทึกใน `assets/characters/` เก็บพรอมป์และพาธชีตในทะเบียนเพื่อใช้งานต่อ

## ฉากและตำแหน่ง

แผนใน `production/chapters-*.json` บันทึกแต่ละภาพด้วย `after` เป็นเลขย่อหน้าที่จะแทรกต่อท้าย เริ่มนับที่ 1 และข้ามย่อหน้าว่าง `characters` ใช้ชื่อจากทะเบียน `brief` อธิบายเหตุการณ์และองค์ประกอบภาพ `alt` อธิบายสิ่งที่อยู่ในภาพเป็นภาษาไทย

เลือกเหตุการณ์ต่างกันอย่างน้อย 5 จุดกระจายตลอดตอน อ่านย่อหน้าที่อยู่ติดกันเพื่อให้ท่าทาง สถานที่ ชุด และทรงผมต่อเนื่อง แล้ววางภาพหลังย่อหน้าที่ผู้อ่านพบเหตุการณ์นั้น ปรับแผนภาพได้ตามเหตุการณ์จริงโดยเก็บข้อความต้นฉบับตามเดิม

ใช้ skill `imagegen` เจนภาพจาก `imageDirection` ในทะเบียนร่วมกับ `brief` ส่งชีตของตัวละครที่เห็นหน้าเป็นภาพอ้างอิงตามลำดับ พร้อมระบุว่าชีตแต่ละใบเป็นของใคร รักษาโครงหน้า ตา จมูก ริมฝีปาก และอายุตามชีต ให้สีหน้า มุมมอง ท่าทาง และชุดเปลี่ยนตามเนื้อเรื่อง ถ้าฉากหมู่เกินจำนวนชีตที่เครื่องมือรับได้ ให้จัดเฟรมคนที่ดำเนินเหตุการณ์ให้เห็นหน้าชัด

ตรวจภาพกับเนื้อเรื่องและเทียบใบหน้า ชุด และทรงผมกับภาพใกล้เคียงในเหตุการณ์เดียวกัน บันทึกภาพฉากแนวนอนเป็น WebP ที่ `assets/illustrations/NN/SS.webp` โดย `NN` คือเลขตอน และ `SS` คือลำดับภาพในแผน เปิดไฟล์ปลายทางตรวจอีกครั้งหลังบันทึก

ถ้าเครื่องมือแจ้งโควตาเต็ม ให้เก็บภาพที่ได้แล้ว รายงานลำดับที่ยังขาดจากสคริปต์ตรวจภาพ และระบุเวลารีเซ็ตเมื่อระบบแจ้ง ใช้ Image API แบบมีค่าใช้จ่ายเมื่อผู้ใช้เลือกวิธีนั้นและตั้งค่าคีย์ไว้แล้ว
